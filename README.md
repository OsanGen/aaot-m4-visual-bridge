# A Request Is Not Permission

AAOT Module 4’s seven-scene, presenter-led teaching bridge. Follow one unassigned task from the planning board to a request to change the draft. The walkthrough connects the Prezi’s known allocation result to the questions people will test in the live exercise.

[Open the live demo](https://osangen.github.io/aaot-m4-visual-bridge/), or open `index.html` in a browser to run it locally. Use **Previous** and **Next** or the left and right arrow keys. Slides 4 and 5 each have one presenter-paced reveal. The narration appears on the slide. The last slide gives the cue to switch to the live Part 1 session.

The app uses fictional work records and runs entirely in the browser. GitHub Pages serves the root of the default branch.
