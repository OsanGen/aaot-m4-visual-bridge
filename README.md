# A Request Is Not Permission

AAOT Module 4’s seven-scene, presenter-led teaching bridge. The kitchen planning board illustrates current records, eligible capacity, the review of a received request, and the evidence a human needs to make a decision.

[Open the live demo](https://osangen.github.io/aaot-m4-visual-bridge/), or open `index.html` in a browser to run it locally. Use **Previous** and **Next** or the left and right arrow keys. Slides 3, 4, and 5 each have one presenter-paced reveal. The narration appears on the slide. The last slide gives the cue to switch to the live Part 1 session.

The app uses a synthetic fixture and runs entirely in the browser. GitHub Pages serves the root of the default branch.
