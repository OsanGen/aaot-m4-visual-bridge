# A Request Is Not Permission

AAOT Module 4’s 13-slide, presenter-led teaching bridge. Follow one unassigned task from the planning board to a request to change the draft. Task tickets and worker time bars show how the draft uses the available minutes. The walkthrough connects the Prezi’s known allocation result to the questions people will test in the live exercise.

[Open the live demo](https://osangen.github.io/aaot-m4-visual-bridge/), or open `index.html` in a browser to run it locally. Use **Previous** and **Next** or the left and right arrow keys. On slide 8, use Next to reveal the workflow, then Next again for the three checks. Each slide uses a short animation to illustrate its main idea as you move forward. With reduced motion enabled, the deck shows the same content immediately. The narration appears on the slide. Slide 12 gives the files and first prompt for the live Part 1 session. Slide 13 shows the Part 2 steps and what to look for.

The app uses fictional work records and runs entirely in the browser. GitHub Pages serves the root of the default branch.
